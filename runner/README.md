# Lectoryx ローカル実行ツール

Lectoryx の Julia 演習を、**この PC にインストールした Julia** で実行・採点するためのツールです。
ブラウザの Lectoryx とだけ通信し、PC の外には何も送りません（127.0.0.1 だけで待ち受けます）。

## はじめに（1 回だけ）
1. Julia をインストールします（https://julialang.org/install/ の juliaup）。
   - Windows：Microsoft Store の「Julia」、または `winget install julia -s msstore`
   - Mac：ターミナルで `curl -fsSL https://install.julialang.org | sh`
2. このフォルダ（`lectoryx-runner`）を、分かりやすい場所（ドキュメントなど）に置きます。

## 使うとき（毎回）
1. **Windows** は `start-windows.cmd`、**Mac** は `start-mac.command` をダブルクリックします。
   - 初めてのときは OS の確認が出ます。Windows は「詳細情報」→「実行」、Mac は右クリック →「開く」。
   - ターミナルから `julia lectoryx-runner.jl --open` でも起動できます。
2. ブラウザで Lectoryx のライブラリが開き、「PC の Julia とつなぎました」と出れば準備完了です。
   - Chrome・Edge では、最初に「このデバイスのほかのアプリやサービスへのアクセス」を **許可** してください。
   - **Safari では使えません**（Safari は Web ページから PC の中のツールへの接続を禁止しています）。Chrome・Edge・Firefox を使ってください。
3. 演習のある講義を開き、カードの「開く」で問題を解きます。
4. 使っている間は、ツールの黒いウィンドウを **閉じないで** ください（閉じると実行できなくなります）。

## 教材の環境（パッケージ）
パッケージを使う演習は、最初に実行するときだけ、パッケージのダウンロードと準備に数分かかります（ネットワークが必要。画面に進み具合が出ます）。
一度準備すれば、次からはネットワークなしで、すぐに実行できます。授業の前に一度開いておくと安心です。

## うまくいかないとき
- 「PC の Julia が見つかりません」：ツールのウィンドウが開いているか、ブラウザで接続を許可したかを確かめてください（Chrome はアドレスバーの左のアイコン →「サイトの設定」）。
- 「合言葉が違います」：ツールのウィンドウに出ている「ペアリング用 URL」をブラウザで開き直してください。
- 「ポートを使えません」：ツールがすでに起動しています（ウィンドウが 2 つ開いていないか確かめてください）。

## 安全のための仕組み
- この PC の中（127.0.0.1）からの接続だけを受け付けます。
- Lectoryx のページ（設定ファイル `lectoryx-runner.toml` に書かれた配信元）からの接続だけを受け付けます。
- 最初の接続で合言葉（`~/.lectoryx/token`）を確かめます。合言葉を作り直すには `--new-token` を付けて起動します。
- 実行するのは、あなたがエディタに書いたコードと、教材のテストです。あなたが自分で Julia を実行するのと同じ権限で動きます。
- 作業用のファイルは `~/.lectoryx/` に置きます（不要になったら消してかまいません）。
